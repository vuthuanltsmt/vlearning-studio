# Final Acceptance Checklist

Đánh dấu tất cả trước khi coi bản cài đặt là sẵn sàng sử dụng.

## Editor
- [ ] Projects mở được.
- [ ] Tạo/mở/đổi tên/nhân bản/xóa dự án.
- [ ] Thêm/xóa/nhân bản/đổi tên trang.
- [ ] Upload video và video còn sau F5.
- [ ] 7 loại câu hỏi tạo/lưu/sửa được.
- [ ] Completion Settings lưu được.
- [ ] Design Modal lưu được.
- [ ] Course Intro và Course Outro lưu được.
- [ ] Certificate template lưu được.

## Preview
- [ ] Course Intro hiển thị.
- [ ] Resume hoạt động.
- [ ] Video phát/tua đúng quy tắc.
- [ ] Quiz xuất hiện đúng thời điểm.
- [ ] Tính điểm đúng.
- [ ] Chuyển trang/mục lục đúng.
- [ ] Dashboard hiển thị đúng.
- [ ] CSV tải được.
- [ ] In báo cáo hoạt động.
- [ ] Course Outro hoạt động.
- [ ] Certificate chỉ có khi ĐẠT.
- [ ] Review Mode mở được tất cả nội dung.
- [ ] Review Mode không đổi điểm/kết quả.
- [ ] Học lại reset đúng.

## SCORM
- [ ] Export tạo ZIP SCORM12.
- [ ] Fake LMS Initialize thành công.
- [ ] lesson_status đúng.
- [ ] score.raw/min/max đúng.
- [ ] Commit/Finish hoạt động.
- [ ] Resume sau đóng/mở lại hoạt động.
- [ ] Course Intro hoạt động.
- [ ] Mục lục hoạt động.
- [ ] Fullscreen hoạt động.
- [ ] Dashboard/CSV/print hoạt động.
- [ ] Course Outro hoạt động.
- [ ] Certificate hoạt động.
- [ ] Review Mode không đổi score/status LMS.

## Production
- [ ] `npm.cmd run build` thành công.
- [ ] `START-VLEARNING.cmd` mở được `/projects`.
- [ ] Tạo một backup `.vlearning.zip` thử và restore thành công.
