-------

If A16 database already works, NO Prisma setup is required.

Then:
  Remove-Item .\.next -Recurse -Force -ErrorAction SilentlyContinue
  npm.cmd run build
  .\START-VLEARNING.cmd

  http://localhost:3000/projects
