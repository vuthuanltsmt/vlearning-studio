SERVER ENFORCEMENT
------------------
- /editor/demo is guarded server-side: ADMIN or TEACHER only.
- /api/admin/* is guarded server-side: ADMIN only.
- Disabled accounts cannot log in.
- Role/status changes invalidate that user's sessions.
- The signed-in admin cannot demote/disable/delete itself through Admin.
- The final active admin cannot be removed.

DATA SCOPE
----------
Role-based access is server-backed.
Projects/videos/games still use the existing local browser/IndexedDB storage.
They are not yet owned/scoped per server account.
